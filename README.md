# Everyday Things, Two Lines

A two-line explanation of rain for a 10-year-old: the first line pictures rain as the sky tipping over a giant watering can, and the second line honestly says what that watering-can picture gets right and what it leaves out, so the picture lands whole without leaving the wrong idea behind.

## How it works

Run `python3 main.py` and it writes exactly two lines of text to `/output/entry.txt` (or the path in `ENTRY_OUTPUT`). The program validates the output before writing: 1–400 characters, exactly two lines, not only whitespace.
